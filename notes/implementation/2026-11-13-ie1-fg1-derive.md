# IE-1 and FG-1: the item-effect guard and the fold's seed check

IE-1 places planner request `6fba1c18` (builder request `586475dc`). FG-1
places planner request `a5fb4a42`. Ruling `8f63f164` keeps the guard's
signature and the `satisfies` map, asks for one compile probe, and permits
both kernel changes.

## IE-1: `isItemEffect`

`packages/derive/src/item-effects.ts:25` exports
`isItemEffect(effect: Effect | GenesisEffect): effect is ItemEffect`. It tests
the effect's kind against `ITEM_EFFECT_KINDS` at `item-effects.ts:18`. The map
has one key for each kind of `ItemEffect` and `satisfies
Record<ItemEffect["effect"], true>`. A kind added to `ItemEffect` and not to the
map fails to compile. A key in the map that `ItemEffect` does not hold also
fails to compile.

The guard takes a `GenesisEffect` too. `ItemEffect` holds the encoded self of a
genesis draft, so it is no subtype of `Effect`. `fold.ts` re-exports
`isItemEffect` beside `changeItem`.

`packages/derive/test/item-effects.test.ts` holds the compile probe.
`narrowed` returns the guarded `Effect` as an `ItemEffect`. If the guard returns
`boolean` instead of `effect is ItemEffect`, `tsc -p
packages/derive/tsconfig.test.json` fails at that line. A `@ts-expect-error`
line, `unguarded`, shows that an `Effect` without the guard is no `ItemEffect`.
A trial with the predicate changed to `boolean` gave TS2322 at `narrowed`.

## FG-1: the fold refuses a seed that names another definition

`applyEntry` at `packages/derive/src/fold.ts:77` throws
`FoldError("the genesis seed names another definition")` at `fold.ts:83`. It
throws when the genesis seed names a definition digest that differs from the
digest of the definition the fold runs under. A seed that names a platform
definition, such as `platform:directory@1`, is no digest, so the check passes
it.

The genesis judge already refuses that seed. `genesisJudged` at
`packages/derive/src/genesis.ts:123` returns `unverified("the seed names
another definition")` at `genesis.ts:141`. The fold check makes a recorded
genesis meet the same rule as a judged one.
