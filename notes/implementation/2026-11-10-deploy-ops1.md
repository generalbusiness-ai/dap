tracked legacy `register` mode. It adds no mode input, variable override,

The bundle hash describes dry-run output. It hashes a sorted list of
relative file names, byte counts and exact SHA-256 values, then hashes
that JSON list. It excludes the generated root README.md and source maps.
Pinned Wrangler source writes a timestamp into that README and includes
maps in outdir. The hash does not prove an uploaded payload or a kept live
variable. The receipt carries this qualification and records the config's
separate byte hash. A hash comparison between commits therefore compares
their emitted modules, not their live host settings.

and configuration history. Scripted fetch replaces only HTTP observations.
