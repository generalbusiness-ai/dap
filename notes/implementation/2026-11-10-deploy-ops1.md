## Decisions and why

Planner ruling `5b38cde5` and correction `28696bae` require tracked offer
expectations: 200 and the exact register when declared, 404 when absent.
No input can substitute another expected offer. The command deploys each
reviewed configuration without a mode input, variable override, legacy
refusal or configuration edit. S2 now sets the tracked legacy index mode
to `enforce`. The planner's 16:03 EST register-mode observation belongs to
the earlier configuration, not this integrated source.

The bundle hash describes dry-run output. It hashes a sorted list of
relative file names, byte counts and exact SHA-256 values, then hashes
that JSON list. It excludes the generated root README.md and source maps.
Pinned Wrangler source writes a timestamp into that README and includes
maps in outdir. The hash does not prove an uploaded payload or a kept live
variable. The receipt carries this qualification and records the config's
separate byte hash. A hash comparison between commits therefore compares
their emitted modules, not their live host settings.

A scripted Wrangler replaces only the child-process/provider boundary.
Tests use a real temporary Git repository for clean status, exact commits
and configuration history. Scripted fetch replaces only HTTP observations.
Neither witness proves a real deployment, edge behavior or room continuity.
The planner runs the first deployment after landing.

integrates main `df41e599` after planner END `0b9724f9`. It preserves the
