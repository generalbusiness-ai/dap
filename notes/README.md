# Notes

Status: current.

`notes/` is the record of how the project got here. Each dated note in
this directory and each plan carries a status line after its title that
says whether it is current, landed, superseded or retired.

| Directory | What it holds |
|---|---|
| `notes/*.md` | Dated design notes and reviews. They stay in place so links keep working. |
| `plans/` | Plans with live work; `plans/README.md` is the index. |
| `plans/retired/` | Plans with no live work, with their status lines. |
| `implementation/` | Delivery records, one note per landing head, and their evidence manifests. No status line. |
| `reports/` | Sprint and daily reports. No status line. |
| `reviews/` | Review records. No status line. |
| `retired-guides/` | Guides of the earlier model, kept for reference. `docs/` describes only the current system. |
